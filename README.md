# Bionex Advanced Prosthetic Arm

Bionex is a cost-effective 3D printed prosthetic robotic arm using EMG-based muscle signal control, ESP32 real-time processing, and MG996R servo motors for finger actuation.

## Run Locally

```bash
npm install
npm run dev
```

Open:

```bash
http://localhost:5173
```

## Add Images

Put your project images inside:

```bash
public/images/
```

Required names:

```bash
bionex-front-hand.jpg
bionex-inner-circuit.jpg
power-supply-ac.jpg
power-supply-battery.jpg
system-overview.jpg
```

## Deploy on Vercel

- Framework: Vite
- Build command: npm run build
- Output directory: dist

## Tech Stack

React, Vite, Tailwind CSS, Framer Motion, Lucide React

## Project Tech

ESP32, EMG Sensor, MG996R Servo Motors, LM2596 Buck Converter, 3D Printed Prosthetic Arm, Embedded C
